START HERE — FOLLOW THESE STEPS

1) Install Python (3.10 or newer) and VS Code.
2) Open this project folder in VS Code.
3) Open Terminal and run:
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
4) Open notebook.ipynb in VS Code or Jupyter.
5) Run all cells from top to bottom. First run needs internet to download the UCI dataset.
6) Confirm the model file appears in models/ and metrics file in reports/.
7) Run:
   streamlit run app.py
8) Test several input combinations.
9) Fill the presentation placeholders with real charts, metrics, names, app URL, and GitHub URL.
10) Push the project to GitHub and deploy app.py on Streamlit Community Cloud.

IMPORTANT:
- Do not write fake metrics.
- The Streamlit app requires the model generated by the notebook.
- The presentation is a ready-to-fill 10-slide template, not a claim that the project has already been run or deployed.
